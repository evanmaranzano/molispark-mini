## 已知问题

### 1. 发布页 placeholder 错位 — 已修，待视觉验证

`pages/drafts/index.less`（publishForm / feedback 共享）：单行 input 改 `height:80rpx + line-height:80rpx + padding:0 20rpx` 垂直居中；textarea 固定 `line-height:44rpx`；`.form-placeholder` 去掉 line-height 改为继承组件固定行高（消除无单位倍数在原生层的歧义）。需开发者工具确认；若仍有残留，看截图后可能微调数值或查 scroll-view 内原生组件兼容。

### 2. 头像字段名不一致 — 已修

`cloudfunctions/login/index.js` 原读 `user.avatarFileID`，updateProfile 写 `avatarUrl`，导致登录 profile.avatarUrl 取不到值。已改为读 `user.avatarUrl`。**需重新部署 login 云函数才生效。**

### 3. db.js add() catch 降级日志

`utils/db.js` 的 `add` catch 块 `console.error` 打印降级日志（v0.1 调试用），v0.2 抽 mock fallback 中间层时统一移除。已在顶部注释标注。

### 4. cloudfunctionRoot — 已修

`project.config.json` 从 `/cloudfunctions` 改回 `cloudfunctions/`（CLAUDE.md 第 56 行要求尾部斜杠），否则 UI 增量上传可能报 `Cannot read property 'region' of undefined`。
